# readme_tool

A sample fixture: list a catalog's entries. Its options are documented the way most
READMEs do it, as the tool's pasted `--help` output:

```text
usage: readme_tool.py [-h] --catalog CATALOG [--limit LIMIT]

List a catalog's entries (sample fixture).

options:
  -h, --help         show this help message and exit
  --catalog CATALOG  Catalog file to read.
  --limit LIMIT      Entries to show. (default: 10)
```
