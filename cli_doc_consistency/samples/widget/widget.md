# widget.py

A tiny sample CLI for hand-verifying `cli_doc_consistency`. Its documentation is
intentionally drifted from the code so a by-hand run shows real catches.

## Usage

```text
widget.py --input FILE [--count N] [--verbose]
```

| Option | Required | Meaning |
| --- | --- | --- |
| `--input FILE` | yes | Widget file to frob. |
| `--count N` | no | Number of times to frob. |
| `--verbose` | no | Chatty output. |
